# Beluga-Fecal-Microbiome-Project-
The goal of this study is to characterize the fecal microbiome of Beluga whales over time housed at the Georgia and Shedd Aquariums. In doing so, we aim to : 1) characterize the fecal microbiomes of individuals over time and 2) compare microbiomes between facilities. 

Required Packages
